# Callisto — macOS Menu Bar Google Calendar App

## Project Overview

A **menu bar only** macOS application, its main objective is to manage meettings,
calendar events are just medium where the meeting schedule is stored.

## Project Structure

The project is structured as follows:

- `./calendar`: native masOS application build in Swift
- `./hompage`: a web-based homepage for the app build with astrojs and deployed
                on Cloudflare Workers
